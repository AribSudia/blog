معظم الـ skills تنفّذ **شيئاً واحداً**.

`/arib-engine` يشغّل **حملة كاملة**.

---

## ما هو `/arib-engine`؟

أعطه ملكية هدف، وسيكتشف backlog خاص به، ثم يدور في حلقة:

```
discover → ship → verify → integrate → record
```

عبر PRs صغيرة وقابلة للتراجع — ويقرر **متى ينتهي بالدليل**، لا حين تأمره بالتوقف.

هو الابن المستمر لـ wave overlay:
- **Wave**: تُنفّذ PLAN معروف حتى الاكتمال
- **Engine**: *يجد* العمل بنفسه ويواصل حتى يجتاز اختبار الإغلاق

---

## حالات الاستخدام — كيف تستدعيه

| تريد… | الأمر | ما يحدث |
|-------|--------|---------|
| **جولة واحدة مُركّزة** | `/arib-engine harden auth + payments` | دورة `discover→ship→verify` واحدة على ذلك الهدف، ثم **يتوقف** |
| **حملة مستمرة** | `/loop /arib-engine <goal>` | `/loop` يضبط الإيقاع (event-gated + heartbeat)؛ الـ engine يعمل دورة بعد دورة حتى يجتاز اختبار الإغلاق |
| **"اصنع كل شيء"** (بدون نطاق) | `/arib-engine` | وضع Autonomous — يجد ويشحن كل تحسين مُتحقق منه، نزولاً بالخطورة، حتى يُنجز |
| **تنسيق الـ toolkit كاملاً** | `/arib-engine --with-arib-family <goal>` | يصبح المايسترو: يقود مهارات `arib-check-*` و`arib-dev-*` و`arib-docs-*` في كل مرحلة (يتراجع للتنفيذ المباشر عند غياب أي منها) |
| **دمج PRs الخضراء تلقائياً** | `/arib-engine --auto-merge <goal>` | Opt-in فقط، ومع branch protection يُطبّق الفحوصات — **أبداً** لـ PRs المال/المصادقة/الامتثال |

---

## مستقل بشكل افتراضي

بدون `--with-arib-family`، الـ engine **مكتفٍ بنفسه وقابل للنقل** — ينفّذ كل مرحلة داخلياً ولا يمتد لمهارات أخوة، حتى لو كانت مثبّتة.

تنسيق العائلة **opt-in صارم**.

## الحلقة الداخلية

```
┌─────────────────────────────────────────┐
│           /arib-engine loop             │
│                                         │
│  1. DISCOVER  → يجد العمل المتحقق منه  │
│       ↓                                 │
│  2. SHIP      → PR صغير قابل للتراجع   │
│       ↓                                 │
│  3. VERIFY    → يختبر بالدليل           │
│       ↓                                 │
│  4. INTEGRATE → يدمج إذا نجح            │
│       ↓                                 │
│  5. RECORD    → يسجّل للذاكرة           │
│       ↓                                 │
│  اختبار الإغلاق → نجح؟ توقّف. فشل؟ كرّر│
└─────────────────────────────────────────┘
```

---

## لماذا هذا مختلف؟

الأدوات التقليدية تنتظر أوامرك في كل خطوة.

`/arib-engine` يتصرف كمهندس مستقل:
- **يُحدّد الأولويات** بالخطورة، لا بترتيب القائمة
- **يتوقف بالدليل** — اختبار الإغلاق هو المعيار، لا "قلت لي أتوقف"
- **يبقى آمناً** — PRs صغيرة وقابلة للتراجع، وحماية مزدوجة لـ PRs المال والمصادقة
